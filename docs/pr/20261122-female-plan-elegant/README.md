# 女性版计划页姿势概念 B · 优雅展示

## 方案

在同一套女性角色与 FitCheck 详情版式上，采用更舒展的运动展示姿势：轻微转体、重心转移、自然打开的肩线和延展的手臂线条。灰白石膏、运动背心与短裤保持一致，强调运动雕塑的自然体态与部位轮廓。

此 PR 仅用于视觉方向评审，不接入 App，不替换现有资源。图中生成文字仅作布局示意，最终 UI 仍以应用组件为准。
