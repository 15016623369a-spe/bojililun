# 女性版计划页姿势概念 A · 基础展示

## 方案

基于现有男性版计划详情页的七部位结构，提出女性雕塑人物方案。延续 FitCheck 的点阵背景、灰白石膏材质、雾银抽屉与炭黑按钮。角色穿运动背心和短裤；姿势以部位展示为主，便于先确认女性人物比例、七部位映射和整体版式。

此 PR 仅用于视觉方向评审，不接入 App，不替换现有资源。图中生成文字仅作布局示意，最终 UI 仍以应用组件为准。
