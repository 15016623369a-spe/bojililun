## 从参考图复刻的整体语言

- **底色和排版。** 主面用雾银灰，计划首屏为 `#E7E8E4`，其他屏幕可在 `#E2E3DF` 附近变化，主字 `#141513`。大标题紧凑有分量，次级信息用中灰。中文优先苹方或系统无衬线，数字用 Helvetica Neue 或同系统无衬线，单位紧跟数值。页面以一张完整画布承载一个视觉主体，靠留白与细分隔线组织信息。
- **颗粒和刻度。** 圆点网格是低对比背景。数据视图可以用点阵构成计时数字和语音波形，用细刻度表现每日容量和组间休息。正文、入口文案和按钮使用清晰的实体字。模型、数字、波形或图表按所在页面选一个做主角。
- **亮色各自有用途。** `#F2ED21` 柠檬黄用于计划里的选中锚点、容量柱和计时弧上的重点。统计稿用雾蓝 `#91BCE8` 表示时长、珊瑚红 `#F06351` 表示展开的肌群或实时语音、淡紫 `#BDADF0` 承载动作曲线。页面先确定当前要读的那个数据，再给对应控件和标记同一种强调色。
- **动效有因果。** 横向切换适合并列视图，面板随选中目标在视线下方展开。切容量和时长时，同一日期的柱子、读数、单位和强调色同时更新。计划首屏的模型随手势旋转，停下后画面稳定，保留「拖动旋转」的提示。肌群切换与镜头移动的节奏以能看清目标为准。

## 计划首屏

设计稿中的单屏是 `342 × 661`。顶部左侧放 FitCheck 标识，右侧是「训练计划」和小圆菜单。大标题「点选肌群」靠左，起点约 `x=21、y=68`，字号约 `31px`。人体是首屏唯一的大图，正面视角起步，居中完整展示从头到脚。人体区相对画布顶端约 `116px`，左右留约 `12px`，底部留约 `91px` 给提示和导航。旋转提示与图标居中，底部是居中的炭黑胶囊导航，浅色小胶囊选中「计划」，其余为「记录」「回顾」。

### 原静态稿的点阵画法

原稿用项目内的 [正面模型图](../../../public/models/sculpture/stats-front.png) 生成 Canvas 2D 参考画面。两层点阵的疏密差异是复刻重点。以下是从原生成逻辑提取的参数，单位为 Canvas 像素。

```text
内部画布 520 × 810，按比例把原图居中放入，高度占 96.5%。
采样前保留该居中图的 RGBA。
底层用 66% 不透明度画一份模型，滤镜为 grayscale(1) contrast(1.18) brightness(.91)。
横纵每隔 5 像素采样一次，原图 alpha < 90 的位置跳过。
tone = max(0, (252 - 原图 R 通道) / 128)
圆点半径 = 0.46 + min(1.22, tone) × 1.78
圆点色 = rgba(20, 26, 20, 0.4 + min(1, tone) × 0.6)
```

原稿模型区宽约 `318px`，点阵间距显示出来约 `3 CSS px`。适配视口时保留圆点形状和屏幕上的视觉尺度，先以同一比例截图对照。正常观看距离下应先看见完整人体，再看见细点的纹理。

### 点选后的详情

镜头聚焦当前部位，人物以灰白石膏光影突出肩、手臂、腿或臀，点阵继续留在背后。肌肉用中性灰表现。下方沿用雾银面板、细分隔线和炭黑实心按钮，出现当前部位名、「动作库」「我的动作库」与「开始训练」。腿部和臀部按参考图降低机位，膝盖或大腿后侧出现在面板上沿上方。设计图中的人物姿势用于对照构图。

## 3D 旋转与实际落地

**旋转版可复用现有 3D 模型和肌群标签。** 原概念图是静态处理的正视图，现有项目已经用 Three.js 渲染男女 GLB，支持拖动与肌群命中。工程入口见 [SculptureBody](../../../components/fc/SculptureBody.tsx) 和 [模型与肌群映射](../../../lib/sculpture-groups.ts)。

1. 用现有模型、灯光和相机渲染到 WebGL 纹理，输出中性灰光照，保留模型透明轮廓。将点阵作为屏幕空间后处理，由当前视角的亮度与轮廓决定每格圆点的大小和深浅。拖动时刷新采样，同一块肌肉转到另一面会按新光影形成点阵。
2. 背景点阵固定在屏幕上。渲染后处理的网格尺寸按 CSS 像素与 DPR 换算，保持圆点和间距，边缘做抗锯齿。原有肌群射线命中继续使用真实网格，选中标签作为单独的 UI 层跟踪模型。共享组件中的回顾热力材质继续由回顾页控制。
3. 旋转时把处理留在 GPU，保留现有按需重绘。避免把每帧读回 CPU 再遍历 Canvas，原静态 Canvas 算法只供对照。实机试看快速拖动、停止及正侧背过渡，重点观察点阵闪烁、锯齿、摩尔纹和掉帧。该方案尚需用手机验证实际帧率。
4. **转身和摆姿是两项工作。** 已检查当前男女 GLB，两者都无骨骼蒙皮和动画轨道。拖动转身可以继续用这些模型。若要实时从站姿过渡到侧平举、双二头或后点步，要给现有网格绑定骨骼、做蒙皮及姿势动画，同时验证变形后的肌群标签与命中。初版也可用当前 3D 选区完成互动，再转场到已出好的姿势图。

## 交接时怎样看复刻结果
