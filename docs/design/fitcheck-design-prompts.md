# FitCheck 交互与视觉风格提示词

这份文档把 FitCheck 现在的交互设计和视觉风格写成可以直接复制的提示词，交给 AI 设计工具、编码助手、图像模型或新加入的设计师时使用。所有数值都取自当前代码（`app/globals.css`、`app/motion.css`、`app/v-review-wall.css`、`app/v-backdrop.css`、`app/theme-dark.css`），改代码后请同步这里。

怎么用：

- 只想要一个总方向：复制 **第 1 节「总提示词」**。
- 做某一类页面或组件：在总提示词后面接上 **第 2 节** 对应的分场景提示词。
- 要落到像素和毫秒：把 **第 3 节「参数速查」** 一起贴上。
- 出稿或写完代码后：用 **第 5 节「验收清单」** 逐条对。

## 1. 总提示词（直接复制）

```text
你在为 FitCheck 设计／实现界面。FitCheck 是以手机为主的中文健身记录应用：选肌群、安排动作、逐组记录重量和次数，记录饮食和体重，再回顾和统计。

【整体气质】
冷静、精密、像一台做工很好的仪器。大面积冷银灰和墨黑，靠超大号数字、细刻度、规整的圆点阵和石膏人体建立质感；彩色只用在当下最该读的那一个数上。高级感来自克制、对齐和流畅的动效，而不是装饰。

【颜色】
- 底：冷银灰 #E2E3DF（计划首屏 #E7E8E4，深一档 #DCDDDA），面板雾银 #EEEEEC。
- 字：墨黑 #151613，次级 #3A3C37，中灰 #6B6D67，浅灰 #8D8F89。
- 强调色各有用途，一屏只突出一个读数：柠檬黄 #F2ED21（容量、选中锚点、主操作「完成第 N 组」）；雾蓝 #91BCE8（时长、体重）；珊瑚红 #F06351（选中的肌群、语音、热量缺口）；淡紫 #BDADF0（动作曲线、个人纪录）；碳水用黄绿 #C9C43A。
- 夜间：近黑 #0E0F10 代替银灰，卡片 #1A1C1F，按钮和导航 #222428，文字 #EEEFEA；选中态反相成浅色胶囊 #ECEBE6 配墨字；柠檬黄只留小面积强调。

【字体与数字】
Helvetica Neue / SF Pro Display + 苹方。页面大标题 34px 粗体。主读数 52–58px、700、字距 -0.04em、等宽数字，末两位用中灰（如 3,9|96）；单位约为数字的 0.4 倍、中灰、紧贴数字。中文标签 13px 600，脚注 10.5–11px 中灰。数字、单位、时间轴对齐同一网格。

【材质】
- 数据块：银灰竖向渐变 #E9EAE6→#DDDEDA，圆角 22，顶部 1px 白色高光，极淡描边，柔和下投影。
- 条形码柱：墨色 1.4px 竖线与 #858780 间隔交替；选中柱换成墨线 + 柠檬黄。
- 圆点阵：6–7px 间距、约 0.8px 半径的浅灰圆点，上下边缘渐隐，用作模型和图表背后的底纹。
- 抽屉毛玻璃：从上到下 34%→26%→44%→66% 的白色透明渐变，backdrop-filter: blur(18px) saturate(1.5) brightness(1.06)，顶部白色高光；背后页面不压暗、不虚化。
- 人体：项目自己的灰白石膏雕塑（正面／背面），保留光影。

【交互原则】
1. 同一类信息用同一种结构：数据块左上标题、右上箭头、中间一个大号读数和一张小图、底部一行脚注。
2. 点开不跳页：按下收缩到 0.97，松手后这块卡片在原位长成毛玻璃抽屉（clip-path 从卡片轮廓长到整屏），背后页面缩到 0.93 并下移 12px。
3. 抽屉里的内容依次升起（每项间隔 45ms），数字从 0 滚到读数，柱子依次长出。
4. 所有图都能按住左右拖动读某一天：读数、标题、关联的对照条一起变；再按一次已选中的那格回到汇总。
5. 收起方式齐全：下拉（超过 140px 或速度够快）、点背后、返回键、Esc、×；收起时抽屉缩回原来那块卡片。
6. 分段控件的选中胶囊带回弹滑过去；换页按底部导航顺序从对应一侧滑入；可点控件按下收缩、松手回弹。
7. 动效有因果：谁被点，谁变；切换区间时同一位置的柱子、读数、单位、强调色同时更新。
8. 每个数都说得清来历：抽屉底部有「怎么算」，估算值写「约／估算」，没过完的今天写「截至现在」，没有数据时告诉用户怎样才会有。

【不要】
不要加阴影很重的卡片、渐变彩色背景、emoji、圆角不一的按钮；不要在一屏里同时用三种以上强调色；不要压暗或模糊抽屉背后的页面；不要为了好看移动用户已经熟悉的入口位置。
```

## 2. 分场景提示词

接在总提示词后面使用。

### 2.1 数据块墙（回顾页这类总览）

```text
做一面「数据块墙」：顶部是通栏主块，下面两列小数据块，间距 8px，最后可以有一块通栏。
- 主块：标题行（左标题、右侧一颗墨色胶囊入口，带四根柠檬黄小柱图标），52px 大号读数 + 柠檬黄对比胶囊（如「↑ 6% 较上周同期」），一排可拖动的条形码日柱（今天是柠檬黄），底部三个小读数（如 训练天数 / 完成组数 / 训练时长）。
- 小数据块：最小高 186px，结构固定——左上标题 13px、右上 14px 箭头；中间一个 24–30px 读数 + 一张小图（折线、圆环、仪表、点阵人体、阶梯柱都可以）；底部一行 10.5px 脚注，左右两端对齐。
- 按数据性质分组，组前用小号分节标题（7px 珊瑚圆点 + 16px 粗体 + 12px 中灰日期）。
- 点数据块任意处（除了图本身）打开它的抽屉；按在图上是读数，不打开。
- 缺资料时，数据块显示一句短说明和「去设置 ›」，点了去补资料。
```

### 2.2 详情抽屉

```text
抽屉从被点的那块卡片原位长出来，占满到状态栏下方 54px，顶部圆角 30。
从上到下：拖动把手（38×5，墨色 20%）；标题行（21px 标题 + 两个 32px 圆形浅底按钮：⤢ 展开全屏、× 关闭）；区间分段「7天 / 30天 / 1年」+ 右侧「截至 11.23」；大号读数区（12.5px 中灰说明 + 58px 数字 + 单位 + 一颗状态胶囊）；主图（可拖动取值）+ 一行提示「— 按住柱子左右拖，看每一天」；次要列表或排行；三列统计（最低 / 平均 / 最高，中间居中、右侧右对齐，上方一条细分隔线）；「怎么算」说明卡（浅底圆角 16）；最后一行进入更深页面的入口（墨色圆形图标 + 标题 + 小字说明 + 箭头）。
材质是通透毛玻璃，背后页面只缩小不压暗；打开时内容按 45ms 间隔依次升起，数字从 0 滚上来。
1 年按自然月聚合，标签写「12月、1月…」。
```

### 2.3 图表

```text
图表一律可交互：按下选中手指下那一格，拖动跟着换，再点一次选中项回到汇总；选中格变色、下方日期加粗；读数用 320ms 滚到新值。
- 柱：条形码纹理；选中柱用强调色（容量用柠檬黄条纹，缺口用珊瑚实色）；空数据画 4px 灰色短桩；可有负值（零线在中间）。
- 建议区：用 13% 珊瑚底 + 上下两条珊瑚虚线标出一段区间，右上角小字「建议区」。
- 折线：2.4px 圆头线从左往右画出（1.1s），下方同色 22%→0 渐变面积，数据点依次弹出；虚线是均线；拖动时有一根虚线竖线和一个空心圆光标。
- 点列：每格最多叠 7 个圆点表示次数，没有就留一个小灰点。
- 矩阵：每天一列圆点，实心 = 达标，描边 = 不足，加墨圈 = 超出，没数据 = 小灰点。
- 堆叠柱：按蛋白（墨）/碳水（黄绿）/脂肪（淡紫）折成千卡堆叠在基线上方，基线下方用珊瑚小点列表示消耗，每点约 60 kcal。
柱子按 min(42ms, 320ms/格数) 的间隔依次从底部长出。
```

### 2.4 人体与肌群

```text
人体一律用项目的灰白石膏雕塑二维正面 / 背面图，并排各占半边：正面图靠右、标注收在左侧；背面图靠左、标注收在右侧。
标注是解剖图式：肌群位置一个墨色圆点（白色描边，大小按数量开方缩放）+ 浅色十字准星 + 虚线引线 + 半透明玻璃小标签（肌群名 10.5px + 数值 13px + 单位）。标签之间至少隔开 13%，超出底部整体上移。
选中某个肌群：点、准星、引线、标签都变珊瑚色，准星旋转 45° 放大，标签略放大，其它列表项降到 45% 透明。
人体背后铺一层上下渐隐的圆点阵。缩成小卡片时只保留点，每个肌群一个点，和大图位置一一对应。
```

### 2.5 计划首屏（点阵人体）

```text
首屏是整屏银灰 #E7E8E4 和一个由细圆点描出的完整人体：点的大小和深浅随人体自身明暗变化（暗处又大又深，亮处又小又淡），背后是 6px 间距的浅灰底点阵。左上大标题「点选肌群」，人体下方居中「拖动旋转」提示。
空闲时不亮任何肌群；手指按住或指向的肌群翻成「墨底亮点」的反相点阵，大标题同步换成肌群名；点下去变成柠檬黄点阵和一个 13px 柠檬黄准星锚点，镜头推近到该部位的石膏姿势，下方升起通透毛玻璃抽屉。
右上角是今日计划胶囊：每个动作一个点，练完点亮成柠檬黄，读数「已练/总数」。
动作库里选中一行时，整行卡片缩小、沿弧线飞进底部「完成」按钮，数量徽标弹一下。
```

### 2.6 训练中

```text
记录一组时屏幕上下两分：上半屏炭黑（动作名、组次、网点插画、超大号重量），下半屏冷银灰（次数、组次卡），刻度尺压在交界线上，可滑动调节。柠檬黄只留给「完成第 N 组」这一个主按钮。夜间上半屏 #0B0C0D、下半屏 #1B1D20，加号白底，当前组只描边。
```

### 2.7 记录页

```text
记录页以「今天」+ 超大号日期定位一天，下面是一整天的条形码式时间刻度（每 10 分钟一根细线，整点加深，记录处变色，柠檬黄小点是现在），再下面是横向滑动的记录卡（训练是柠檬黄卡，饮食是浅色卡，体重卡带一点雾蓝；待确认的卡带珊瑚色小标记），选中卡在下方展开明细。底部是墨色「按住说话」大按钮，长按就地录音：点阵计时、随音量变化的点阵波形和珊瑚色转写区，上滑取消。
```

### 2.8 自定义背景与毛玻璃

```text
用户可以给回顾页和记录页换一张自己的图片：图片固定铺在最底层、不随内容滚动，上面盖一层同色薄纱（白天银灰、夜间近黑）；所有内容浮在毛玻璃上，版式不变。
- 回顾页透明度 t（0–100%，默认 40%）可调：数据块玻璃底色透明度 = 0.84 − 0.5t，薄纱透明度 = 0.5 − 0.36t；玻璃 blur(18px) saturate(1.5) brightness(1.08)。
- 记录页固定用抽屉那种通透玻璃；时间刻度背后垫一条 36% 的淡玻璃。
- 直接压在图上的标题、日期加一圈同色淡光晕保证可读。
- 抽屉本身的玻璃不变，打开后透过去就是这张背景。
- 设置面板放在「我的」：缩略预览（同时示意回顾和记录两种玻璃）、「更换背景」「恢复冷银灰」两个按钮、一条透明度滑杆。
```

### 3.4 毛玻璃配方

```css
/* 白天：抽屉、记录卡 */
background: linear-gradient(180deg, rgb(255 255 255 / 34%) 0, rgb(246 246 243 / 26%) 22%, rgb(240 240 237 / 44%) 60%, rgb(236 236 233 / 66%) 100%);
backdrop-filter: blur(18px) saturate(1.5) brightness(1.06);
box-shadow: inset 0 1px 0 rgb(255 255 255 / 95%), inset 0 0 0 .5px rgb(255 255 255 / 70%), inset 0 18px 30px -22px rgb(255 255 255 / 90%), 0 -24px 48px -30px rgb(21 22 19 / 30%);

/* 夜间 */
background: linear-gradient(180deg, rgb(30 32 35 / 55%) 0, rgb(22 24 27 / 70%) 40%, rgb(16 17 19 / 86%) 100%);

```

背后页面：只缩小（`scale: .93; translate: 0 12px`），不压暗、不虚化。

### 3.5 动效曲线

```css
/* 轻微过冲：换页、抽屉长出、内容升起、柱子生长 */
--spring: linear(0, 0.006 1.1%, 0.024 2.2%, 0.094 4.5%, 0.393 11.5%, 0.615 17.4%, 0.77 23.1%, 0.878 29%, 0.947 35.3%, 0.988 42.2%, 1.008 50%, 1.015 59.3%, 1.013 71.3%, 1);
/* 明显回弹：松手、胶囊落位、分段指示块 */
--spring-bounce: linear(0, 0.007 1%, 0.029 2%, 0.12 4.2%, 0.503 10.6%, 0.755 15.9%, 0.913 21.2%, 1.014 27.1%, 1.054 31.5%, 1.073 36.4%, 1.072 41.5%, 1.053 47.1%, 1.021 54.3%, 0.999 64.1%, 0.993 75.8%, 1);
/* 不支持 linear() 时的退路 */
--ease-spring: cubic-bezier(.32, 1.25, .4, 1);
--ease-out: cubic-bezier(.2, .8, .2, 1);
```

### 3.6 动效时长

| 动作 | 时长与曲线 | 说明 |
| --- | --- | --- |
| 换页 | 0.62s `--spring` | 按导航顺序从 ±44px 滑入，透明度 0.35→1；动 `left` 不动 `transform`，底栏不跟着滑 |
| 底部导航选中胶囊 | 0.56s（跨两格 0.62s）`--spring-bounce` | 从上一个位置弹过去 |
| 按下 / 松手 | 按下 0.12s ease-out；松手 0.55s `--spring-bounce` | 小控件 `scale .95`，大面积 `.975`，数据块 `.97`，图上的柱 `.92` |
| 分段控件指示块 | 0.55s `--spring-bounce` | 宽度和位置一起动 |
| 卡片长成抽屉 | 640ms `--spring` | `clip-path: inset(卡片四边 round 22px)` → `inset(0 round 30px 30px 0 0)`；卡片本身透明度 0 |
| 抽屉缩回卡片 | 460ms `cubic-bezier(.3,.7,.1,1)` | 内容先在 0.14s 内淡出 |
| 背后页面缩放 | 0.62s `--spring` | `scale .93`，下移 12px；拖动时跟手指按比例回弹 |
| 抽屉内容升起 | 0.62s `--spring`，延迟 110ms + 序号 × 45ms | 从下方 18px 升起并淡入 |
| 数字滚动 | 650ms（拖动取值时 320ms），三次方缓出 | 从上一次的读数滚到新读数 |
| 柱子生长 | 0.75s `--spring` | `scaleY 0→1`，间隔 min(42ms, 320ms/格数) |
| 折线画出 | 1.1s `--ease-out`，延迟 0.12s | 数据点 0.45s `--spring-bounce` 依次弹出 |
| 展开全屏 | 0.55s `--spring` | 顶部距离和圆角一起动 |

### 3.7 手势阈值

| 手势 | 规则 |
| --- | --- |
| 下拉关闭 | 拖动距离超过 140px，或松手速度超过 0.55 px/ms；往上拖只给 0.18 的阻尼 |
| 拖动区域 | 把手和标题栏（按钮除外） |
| 图上取值 | 按下即选，拖动跟随；按已选中的那一格回到汇总；键盘左右键也能移动 |
| 返回键 | 先收起最上层（抽屉 → 页面），每层打开时压一条历史记录 |
| 触感 | 选中、切换时振动 4–10ms（只在用户已经和页面交互过之后） |
| 减少动效 | 系统开启时去掉形变动画、升起和弹簧，只保留结果 |

## 4. 文案与数据规范

- 全中文界面，标签短、动词在前：「去设置」「恢复冷银灰」「在训练统计里看 · 总览」。
- 数字和单位之间不空格或只用细间距，单位永远跟在数后面：`72.1 kg`、`2,618 kcal`、`3.1 小时`。
- 区间写清楚：「近 7 天」「近 30 天」「近 12 个月」「截至 11.23」「11.16 — 11.22」。
- 估算值写「约」或「估算」；当天还没过完写「截至现在」，不急着下结论。
- 每个新指标都给一张「怎么算」说明卡，写公式、数据来源和口径取舍（例：每日总代谢 = 基础代谢 × 活动系数，不叠加运动消耗）。
- 空状态告诉用户怎么才会有数据：「在「记录」里说一句「体重 72.1」」。
- 对比写方向和对象：「↑ 18% 较上周同期」「与前 7 天持平」。

## 5. 验收清单

- [ ] 一屏里是否只有一个最突出的读数，强调色是否和它的数据类型对应？
- [ ] 数字是否等宽、末两位中灰、单位紧贴？
- [ ] 同类卡片结构是否一致（标题、箭头、大数、小图、脚注）？
- [ ] 点开是否在原位长出抽屉，背后只缩小不压暗？收起是否回到原卡片？
- [ ] 下拉、点背后、返回键、Esc、× 是否都能收起，收起后滚动和缩放是否复原？
- [ ] 图是否都能按住拖动读数，关联元素是否一起变？
- [ ] 按压回弹、分段胶囊滑动、换页方向是否用的是上面两条弹簧曲线？
- [ ] 夜间是否没有漏掉写死的浅色（浅色写成 `var(--dk-…, 原色)`）？
- [ ] 有自定义背景时，压在图上的字是否还读得清？
- [ ] 每个新数字是否有「怎么算」，估算和未完成的数据是否标明？
- [ ] 系统「减少动效」打开时是否仍然可用？
